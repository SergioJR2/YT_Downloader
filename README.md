# 🎵 YT Downloader — App de Escritorio

Aplicación de escritorio nativa (sin navegador) para descargar videos y audio de YouTube.

## Requisitos
- **Python 3.8+** con "Add Python to PATH" marcado → python.org
- **ffmpeg** (para MP3): `winget install ffmpeg`

## Compilar el .exe
1. Doble clic en `compilar.bat`
2. Esperar 3–6 minutos
3. El .exe queda en `dist\YT_Downloader.exe`

## Usar
- Doble clic en `YT_Downloader.exe`
- Se abre directamente como ventana de escritorio
- Pega la URL → Analizar → elige formato y calidad → Descargar
- Las descargas van a: `C:\Users\TU_USUARIO\Descargas_YouTube\`
